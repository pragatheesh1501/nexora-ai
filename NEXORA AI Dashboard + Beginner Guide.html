Backend setup guide
This HTML includes the dashboard and API client. Browsers cannot securely run a Node.js backend or hide provider secrets, so deploy the backend service separately and connect it above.
1. Install Node.js 20+
2. Extract the NEXORA AI backend starter
3. Run: npm install
4. Copy .env.example to .env
5. Set OPENAI_API_KEY on the server (never in this HTML)
6. Run: npm run dev
7. Set Backend base URL to http://localhost:8787
8. Select Test connection, then try the AI copilot

Required endpoints:
GET  /health
POST /api/assistant/chat
GET  /api/payments/notifications

• HTTPS + strict ALLOWED_ORIGINS
• Real login/session auth and workspace-level authorization
• Server-side secret storage and request auditing
• Payment-provider adapter + signed webhook verification
• Email/Slack delivery providers and delivery receipts
• Playwright/API workers, queues, durable evidence, alerting
• Human approval for refunds, transfers, and disruptive recovery
